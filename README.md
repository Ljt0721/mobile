# SWE311 & DMT321 Mobile Application System Design Tutorials

This repository is a tutorial collection for **SWE311 & DMT321 Mobile Application System Design (Group 2)**, 2026/04, **Amera**.

Each tutorial folder contains the materials for that tutorial, including screenshots and the corresponding Flutter project. Open the Flutter project inside a tutorial folder and run it directly with `flutter run`.

## How to Run

1. Open the tutorial folder you want to view.
2. Check the screenshots and locate the Flutter project inside that tutorial folder.
3. Open the Flutter project in Visual Studio Code.
4. Select a target device from the VS Code device selector.
5. Run the Flutter app from the project directory:

```bash
flutter run
```

Each tutorial project is intended to be run directly as an independent Flutter app.
