# SWE311 & DMT321 Mobile Application System Design Tutorials

This repository is a tutorial collection for **SWE311 & DMT321 Mobile Application System Design (Group 2)**, 2026/04, **Amera**.

Each tutorial folder contains a standalone Flutter app, along with several screenshots captured during development or testing.

More tutorials will be added continuously as the course progresses.

## How to Run

1. Open the tutorial folder you want to run in Visual Studio Code.
2. Select a target device from the VS Code device selector.
3. Run the Flutter app:

```bash
flutter run
```

Each tutorial is intended to be run directly as an independent Flutter project.
